# 🌾 AGRIPrice — Smart Mandi Price Comparison Dashboard

AGRIPrice is a mandi price comparison dashboard designed to help farmers make more informed selling decisions. It lets users compare crop prices across wholesale markets, identify price differences, explore market trends, and set target-price alerts—all in one place.

**Live Demo:** https://agriprice7.netlify.app/

![AGRIPrice screenshot](image.png)

> **Note:** This is a prototype. All prices, trends, AI insights, and sync logs are simulated demo data. There is no backend, database, or live API connection yet.

---

## Features

- **Price Comparison:** Browse mandi price records for 19 crop varieties across 12 markets in 6 states. Filter by category, filter by state, sort by price, name, or arrival volume, and switch between card and table views.
- **3-Mandi Arbitrage Analysis:** Click any crop to compare its price across three nearby mandis and explore potential extra earnings for a given load.
- **Trends & AI Insights:** View a price trend chart drawn on an HTML canvas, along with a market signal panel showing a recommended action and target price.
- **Price Alerts:** Create and delete alerts that trigger when a crop's price rises above or drops below a target.
- **Farmer Profile:** Manage farm details, notification preferences, and a mandi watchlist.
- **System Status:** Explore a data provider toggle and mock sync log. The AGMARKNET mode falls back to demo data.
- **Responsive Layout:** Includes a separate mobile navigation bar for a better experience on smaller screens.

## Tech Stack

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- [Lucide Icons](https://lucide.dev/)
- HTML Canvas for the trend chart

## Run Locally

No installation is required.

1. Clone this repository:

   ```bash
   git clone https://github.com/Karam-dev26/agriprice.git
   ```

2. Open the project folder.
3. Open `index.html` in a modern web browser.

An internet connection is required because Tailwind CSS, Lucide Icons, and the Inter font load from CDNs.

## Current Limitations

- All market data is hardcoded demo data.
- There is no backend, database, or live API integration.
- Alerts and profile changes are stored in memory and reset when the page is refreshed.
- AI insights and market signals are static demo content, not generated by a live AI model.
- The Tailwind CSS CDN setup is intended for prototyping rather than production.
